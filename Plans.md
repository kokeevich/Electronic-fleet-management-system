# Итоговый план проекта

Финальная ветка: main. Этот документ описывает текущее состояние.
Первоначальный план и история уточнений сохранены в
[архиве](docs/archive/development-plan.md); его старые отметки не являются текущим статусом.

## Реализовано

- [x] Подключение к существующей SQL Server БД, внешняя строка подключения.
- [x] Авторизация, регистрация наблюдателя, PBKDF2, разграничение доступа.
- [x] Просмотр, поиск, создание, изменение и безопасное удаление транспорта и реестров.
- [x] Водители, закрепления с проверкой пересечений, документы и сроки.
- [x] ТО/ремонты, запчасти и состав работ; ручной учёт стоимости и остатков.
- [x] История автомобиля: водители, документы, обслуживание и затраты.
- [x] Администрирование пользователей, ролей и сброс пароля.
- [x] Журнал изменений: все события для администратора, собственные для остальных.
- [x] Отчёты по автопарку, расходам, предстоящим и просроченным событиям.
- [x] CSV, печать и PDF через системный принтер.
- [x] Колокольчик, личный счётчик, прочтение, проверки срока и пробега без всплывающих сообщений.
- [x] Инструкции установки, обновления БД и резервного копирования.
- [x] Чек-лист итоговой проверки на Windows.

Пользователь подтвердил работу основных сценариев. Это не заменяет итоговый
прогон финальной ветки на отдельной копии SQL Server по подготовленному чек-листу.

## Принятые границы

Системные роли фиксированы; можно изменить описание. История отдельного водителя
доступна через поиск реестра закреплений; отдельного окна водителя нет.
ТО и состав работ сохраняются отдельными операциями, автоматического списания
склада и пересчёта стоимости нет. Общие настройки типов работ и порогов уведомлений
не добавлены: пороги фиксированы 30 днями / 1000 км. Фоновая работа при закрытом
приложении, всплывающие сообщения и автоматическое резервное копирование не входят
в итоговую версию. Подробности правил и ограничений — в README.
